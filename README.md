# 🎨 Colored Boxes Layout

A responsive layout workshop built using **HTML5** and **CSS3 Flexbox**, featuring custom container alignments, responsive item wrapping, and distinct background color schemes for individual content cards.

---

## 📌 Overview

The **Colored Boxes Layout** project demonstrates modern CSS layout techniques. It utilizes Flexbox properties like `flex-wrap`, `justify-content`, and custom `flex` sizing values to structure and style multiple colorful interactive containers uniformly.

---

## ✨ Key Features

- **Flexible Container Engine**: Built with `display: flex` and `flex-wrap: wrap` to allow fluid reorganization across varying viewport sizes.
- **Precise Item Sizing**: Custom flex properties (`flex-grow`, `flex-shrink`, `flex-basis`) for controlled box dimensions.
- **Thematic Color Palette**: Distinct background shades applied to individual boxes utilizing modifier classes (`box1` through `box6`).
- **Centered Text Layouts**: Flexbox column direction used internally within each card to perfectly center headers and paragraph descriptions.

---

## 🛠️ Built With

* **HTML5**: Semantic markup structure (`header`, `div`, `h2`, `p`).
* **CSS3**: Flexbox layout rules, box-sizing models, borders, border-radius, and customized color selections.
